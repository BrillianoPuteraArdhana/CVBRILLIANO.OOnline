Pengalaman Saya

Selama menjadi siswa SMK Galajuara, saya aktif mengikuti berbagai organisasi dan kegiatan sekolah untuk mengembangkan kemampuan komunikasi, kepemimpinan, teknologi, serta kerja sama tim.

Pengurus OSIS

Saya dipercaya menjadi Bendahara OSIS dan ikut berpartisipasi dalam berbagai acara sekolah seperti Hari Guru, Class Meeting, MPLS, Pensi, Hari Kartini, dan Demonstrasi Ekstrakurikuler. Dari kegiatan ini saya belajar tentang tanggung jawab, kerja sama tim, dan manajemen kegiatan sekolah.

Humas Rohis Al-Ilmi

Saya aktif sebagai pengurus Humas Rohis Al-Ilmi dan membantu kegiatan keagamaan seperti Pesantren Ramadhan, Maulid Nabi, dan kegiatan Islami lainnya. Pengalaman ini membantu saya meningkatkan kemampuan komunikasi dan kerja sama dalam organisasi.

Marching Band

Saya mengikuti ekstrakurikuler Marching Band dan terlibat dalam berbagai penampilan seperti Hari Guru, Karnaval Hari Kartini, Pensi, dan pembagian rapor. Dari kegiatan ini saya belajar disiplin, kekompakan, dan rasa percaya diri saat tampil di depan umum.

IT & Coding Club

Saya mengikuti kegiatan IT dan Coding Club untuk mempelajari dasar pemrograman, HTML, CSS, serta pengembangan website sederhana. Saya juga belajar berpikir logis, problem solving, dan mengembangkan kreativitas di bidang teknologi.

Teknik Komputer dan Jaringan

Sebagai siswa jurusan TKJ, saya mempelajari berbagai materi seperti merakit komputer, membuat kabel LAN RJ45, instalasi jaringan, Microsoft Office, serta dasar desain dan pengolahan data. Jurusan ini membantu saya memahami dunia teknologi dan komputer lebih luas.

Designer & Editing

Saya memiliki minat di bidang desain menggunakan Canva dan editing video menggunakan CapCut. Saya sering membuat poster, presentasi, konten visual, dan desain sederhana untuk kebutuhan sekolah maupun organisasi.
